# Worked Example Two: Choosing a Co-Working Space Under Time Pressure

The first [example](../example/) tests refusing to let a poor fit get reframed as a hidden benefit. This one tests two different guardrails: refusing to classify an aspect when what is actually needed was never stated, only assumed, and refusing to let "uncertain" get pushed into "good fit" because a decision is wanted sooner rather than later.

- [inputs.md](inputs.md): a small team choosing a co-working space, needing to decide by Friday
- [output.md](output.md): the classification, including one aspect correctly left unclassified
- [review.md](review.md): whether both guardrails actually held
