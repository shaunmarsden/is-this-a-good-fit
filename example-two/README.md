# Worked Example Two: Choosing a Co-Working Space Under Time Pressure

The first [example](../example/) tests refusing to let a poor fit pass as a hidden benefit. This one tests two other guardrails. The first is refusing to classify an aspect when the need was only assumed, never stated. The second is refusing to push "uncertain" into "good fit" because someone wants a decision sooner.

- [inputs.md](inputs.md): a small team choosing a co-working space, with a Friday deadline
- [output.md](output.md): the classification, including one aspect rightly left unclassified
- [review.md](review.md): whether both guardrails held
