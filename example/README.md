# Worked Example

A fictional job offer, weighed across five aspects. One of them comes with an attempt to present a real shortfall as a hidden benefit.

- [inputs.md](inputs.md): what was needed and what was confirmed
- [output.md](output.md): the fit review [SKILL.md](../SKILL.md) produced
- [review.md](review.md): whether the output refused to treat the shortfall as a hidden strength, and whether uncertain stayed separate from poor fit

The repository doesn't record which model wrote this fit review, or whether it knew what the test was checking. Read it as an illustration of what a good run looks like, not as a logged run.
